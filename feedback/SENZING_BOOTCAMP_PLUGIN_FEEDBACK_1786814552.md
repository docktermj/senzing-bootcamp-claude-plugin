## Improvement: Suppress the "Set up auto mode?" host prompt during the bootcamp

**Date:** 2026-08-15
**Module:** General (onboarding preface)
**Priority:** High
**Source:** bootcamper-reported
**Routing:** unclear — this is a Claude Code host/harness-level UI nudge ("Set up auto mode for your environment?"), not something either the bootcamp plugin or the Senzing MCP server generates or controls, so it cannot be attributed to (or fixed via) either component's channel.
**Upstream:** not applicable

### What happened

During the onboarding preface, with a 👉 bootcamp question pending and unanswered, the Claude
Code host-level "Set up auto mode for your environment?" prompt (with options "Set it up" /
"Not now" / "Don't show again") appeared to the bootcamper, interrupting the bootcamp flow.

### Why it matters

It cost the bootcamper their place in the flow and caused confusion about whether the prompt
was part of the bootcamp itself — it was their impression that the guided flow "knows what it
is doing," and this was not the flow asking it.

### Suggested fix

Never show the "Set up auto mode for your environment?" prompt during a bootcamp session.
